About Visual Lab.

Visual Lab is a growing collection of standalone HTML visual tools by BeerBelgio / Matteo Belgiovine. Sketch Design Tools is the current host compatibility target, not the identity of the project.

STANDALONE

One HTML file, two current ways to use it.

IN A BROWSER

Open a tool from the catalogue and use its live controls, or download the original HTML file and open it directly in a modern browser. The downloaded file remains the same tool used by the catalogue and tool page.

IN SKETCH DESIGN TOOLS

Import the HTML as a Custom HTML Tool, use the controls exposed by its manifest, and map the controls exposed to Audio Sync where useful.

MAPPING-WISE

Mapping suggestions are starting points, not prescriptions.

Any parameter may be mapped to any useful source. The host or decoder should provide a common transformation layer so incoming signals can be shaped before they reach the visual parameter.

INPUT RANGE

Define the useful min/max of the incoming signal, then normalize or clamp it before mapping. This avoids dead zones and runaway values.

OUTPUT MIN / MAX

Map the normalized source into a chosen sub-range of the visual parameter, so a control can stay inside a useful musical or visual window.

INVERT

Reverse the mapping direction when useful: high input can produce low parameter values and vice versa.

SENSITIVITY / CURVE

Shape how strongly a parameter responds. A linear response is the baseline; adjustable sensitivity or response curves give finer or more aggressive behaviour.

SMOOTHING

Filter fast numerical jitter before it reaches the renderer, reducing nervous or visually noisy modulation.

ATTACK

Control how quickly a mapped value rises, from immediate transient response to a slower swell.

RELEASE

Control how quickly a mapped value falls, allowing tails, persistence and less abrupt visual decay.

DISCRETE / STEPPED

For integer or mode-like controls, quantize, latch or trigger only when thresholds are crossed instead of treating the parameter as continuously variable.

CURRENT SKETCH HOST CONTRACT

Parameters: up to 12 numeric controls. Colors: up to 8 color controls. Audio Sync: up to 12 destinations in the current tested workflow. The 12-destination Audio Sync limit is empirical rather than presented here as an official Sketch API guarantee.

Every Audio Sync key must correspond to a control actually exposed in the tool manifest. A control left manual-only in Sketch is not inherently non-automatable in future browser, Max or Ableton hosts.

HOW IT WORKS

Manifest-driven is an internal architecture choice.

Each tool declares a window.SKETCH_TOOL manifest containing its exposed parameters, ranges, defaults, colors and host-facing control list. The generic Visual Lab page reads that manifest instead of hard-coding a separate interface for every tool.

This is useful technically because the HTML tool remains the source of truth and the same page can host different tools without duplicating their control definitions. It is intentionally not one of the main homepage promises anymore; “Mapping-wise” describes something more meaningful to a visitor.
