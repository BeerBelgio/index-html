## Measurement
- Eight warm-up frames, then fixed real wall-clock window paced by requestAnimationFrame. One submitted pipeline per due slot; no catch-up burst. Record target slots, completions inside window, missed opportunities, late completions, overrun and rAF intervals. FPS is browser pipeline completions per second; cannot certify presented frames or actual display refresh. No synthetic fixed-step throughput claims. GPU completion is separately sampled by timer query when available; disjoint/unresolved queries remain explicit. CPU renderer duration is not GPU time; pipeline includes source generation/bitmap and render but excludes readback. Timing does not add a new gl.finish. No per-pass instrumentation or direct GPU-cost subtraction from dry baseline.
- Dry baseline uses same source, cadence, resolution and window but independent session; Linking Nodes source determinism is not certified. Comparisons are descriptive; repeat runs and native hardware differences matter. Record actual resolution (4K requested clamps to 2048×1152), environment, texture estimate, export SHA and state. No 4K native claim or sustained certification from a short screen. GPU query scope includes upload/composite/FX; texture estimate is not total VRAM.
- Temporal pass: 640×360, 3s simulated time, all frames rendered in order. Static chart for stateless, moving chart for history. Defaults and heuristic activation-max state where selected speed/chance/amount-like continuous controls differ from default; complete state included in report. Sample five times, compare dry and wet on same bitmap/time, RGBA mean absolute difference, changed-pixel fraction, hashes and final dry/wet PNG. No visible difference is an observation, not failure; not exhaustive timing/state or artistic/reference QA. Wet blend is the existing host compositor semantics. All histories reset per state. No algorithm modification.
- Matrix: 195 benchmark records (5 dry + 190 wet), 38 temporal records, total 233. No serial FX yet. JSON preserves partial results and plan; CSV one record per job. PASS means completed measurement; target achievement is separate. CI shortened software pilot is not native evidence.
- QA-01 Intel evidence supplied by maintainer: 5 files, 190/190 module combinations, 1650/1650 parameter cases, 25 history lifecycle checks, actual max 2048×1152, original baseline f38c437. These remain historical evidence, not QA-02 results.
