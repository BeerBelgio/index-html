# INDEX HTML — Third-Party Notices and Inspirations

INDEX HTML contains original HTML visual tools by BeerBelgio / Matteo Belgiovine. **Sketch is a current compatibility target, not the identity or owner of the project.**

The current tool set has been audited against the sources listed below. No distributed tool is currently identified as retaining meaningful third-party implementation code or structure. The relationships below are therefore creative/conceptual references unless explicitly described as internal derivation or same-owner lineage.


## Sketch

Compatibility target: [Sketch](https://tools.sketchdesign.club/)

INDEX HTML tools are designed to work as Custom HTML tools inside Sketch while remaining standalone browser files and compatible with the optional INDEX Browser Host context. Sketch is a third-party platform and is not bundled with this repository. INDEX HTML is an independent project; references to Sketch describe compatibility only and do not imply affiliation, sponsorship or endorsement.
