TOOLS ABOUT GITHUB

A growing collection of standalone visual tools.

Built inside an audio/MIDI-reactive workflow, compatible with Sketch Design Tools, and designed to remain portable beyond a single host.

STANDALONE

Each tool is a self-contained HTML file that can run in a browser and be imported into Sketch Design Tools.

MAPPING-WISE

Parameters are meant to be mapped freely, with range, curve, smoothing, attack/release and stepped handling supplied by the host.

SOURCE-AVAILABLE

Original code is shared for non-commercial use, with creative lineage, internal derivations and licensing documented per tool.
